# 📈 Stock Sense

An ANN-powered S&P 500 trend prediction dashboard built with Streamlit and Plotly. Stock Sense combines a trained neural network with a suite of technical indicators to generate next-day directional signals (UP / DOWN) for the S&P 500.

---

## Features

- **Next-day prediction signal** — UP / DOWN classification with model confidence score and a rolling 5-prediction streak display
- **Interactive price chart** — candlestick-style close price with optional overlays: Bollinger Bands, EMA 10, SMA 10, and buy/sell prediction markers
- **Technical indicator panels** — RSI, MACD with histogram, Volume (color-coded by return direction)
- **Stochastic Oscillator** — with overbought (80) / oversold (20) zones
- **Prediction confidence timeline** — probability curve over the selected date range with an adjustable threshold line
- **Technical indicator distributions** — histograms for RSI, Momentum, and Bollinger Band Width
- **Model training history** — loss and accuracy curves across epochs (requires a saved training log)
- **Model metadata viewer** — accuracy, ROC-AUC, epochs, batch size, learning rate, and full JSON inspector
- **Raw data preview** — last 50 rows with key columns including model probability and prediction


## Installation

**1. Create and activate a virtual environment (recommended)**

```bash
python -m venv venv
source venv/bin/activate        # Linux / macOS
venv\Scripts\activate           # Windows
```

**2. Install dependencies**

```bash
pip install -r requirements.txt
```

## Usage

### 1. Feature Engineering

```bash
python training/feature_engineering.py
```

Processes raw data and outputs `data/engineered_data.csv` with all 26 technical indicator features.

### 2. Train the Model

```bash
python training/train_model.py
```

Trains the ANN, saves the best model to `models/stock_model_best.keras`, the scaler to `models/scaler.pkl`, and writes metadata and training logs.

### 3. Visualize Training Results *(optional)*

```bash
python training/visualize.py
```

Generates plots from the training run for offline inspection.

### 4. Launch the Dashboard

```bash
python -m streamlit run app.py
```

Open [http://localhost:8501](http://localhost:8501) in your browser.

### Sidebar controls

| Control | Description |
|---|---|
| Date Range | Filter the chart and predictions to a specific period |
| Bollinger Bands | Toggle BB High / Mid / Low overlays |
| EMA 10 | Toggle 10-period Exponential Moving Average |
| SMA 10 | Toggle 10-period Simple Moving Average |
| Volume | Toggle the volume bar panel |
| Prediction Threshold | Adjust the probability cutoff for UP vs DOWN (default 0.50) |

## Model & Features

The model is a feedforward Artificial Neural Network (ANN) trained to classify whether the next trading day will close higher (UP = 1) or lower (DOWN = 0).

### Input features (26 total)

| Category | Features |
|---|---|
| Momentum | `rsi`, `macd`, `macd_signal`, `macd_diff`, `stoch`, `momentum` |
| Trend | `ema_sma_ratio`, `trend_3d`, `trend_5d` |
| Volatility | `bb_width`, `bb_position`, `atr_pct`, `volatility_10d` |
| Price structure | `close_position`, `price_range` |
| Signals | `macd_cross`, `rsi_overbought`, `rsi_oversold` |
| Volume | `volume_zscore`, `volume_change`, `v_lag1`, `v_lag2` |
| Returns | `returns`, `r_lag1`, `r_lag2`, `r_lag3` |

Features are scaled with the saved `scaler.pkl` before inference.

## Data

Place your feature-engineered dataset at `data/engineered_data.csv`. The file must contain at minimum:
