# 💳Credit Card Fraud Detection System

A Machine Learning project for detecting fraudulent credit card transactions using Random Forest and XGBoost with SMOTE balancing, cross-validation, and advanced performance evaluation.


## 🚀 Features

- Fraud Detection using Machine Learning
- Random Forest & XGBoost Models
- SMOTE for Imbalanced Data Handling
- Feature Scaling & Data Preprocessing
- ROC Curve & Confusion Matrix Visualization
- Cross Validation for Model Stability
- Feature Importance Analysis
- Learning Curve Visualization
- Model Saving with Joblib

## 🧠 Models Used

| Model | Purpose |
|------|------|
| Random Forest | Stable ensemble learning |
| XGBoost | High-performance fraud detection |


## 📂 Dataset

Dataset Used: Credit Card Fraud Detection Dataset

### Features

- Time
- Amount
- V1 to V28
- Class

### Target Variable

| Value | Meaning |
|------|------|
| 0 | Legitimate Transaction |
| 1 | Fraudulent Transaction |
